# WakeCore

> Open hotword detection for private voice systems.
> Lokale Hotword-Erkennung für private KI-Systeme.

A Python SDK for on-device hotword ("wake-word") detection.
Detection runs locally — no cloud calls, no API keys, no telemetry.

```bash
pip install wakecore[audio]
```

```python
from wakecore import Runtime, AudioCapture

with Runtime.load("hey_computer.wake") as rt, \
     AudioCapture(rt.sample_rate, rt.frame_length) as mic:
    for frame in mic:
        if rt.process(frame):
            print("wake!")
```

Hotword files (`.wake`) are generated by the WakeCore service.

Documentation: <https://wakecore.dev>.
